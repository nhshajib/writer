# Session flow and plan boundaries

The default path is **Set up → Review & start**. Users paste text, keep the recommended Natural rhythm, and approve the exact text. A new Google Doc and a title derived from the opening sentence are defaults; changing the destination or title is optional. A duration is suggested from the text length and plan limits, and remains editable.

The old insertion and timing screens are now optional Advanced settings. Formatting, connection diagnostics, and the detailed schedule preview also open on demand. Existing insertion modes, formatting, scheduled starts, saved presets, and custom timing remain supported. The review screen is the single session summary; there is no duplicate sidebar. The dashboard keeps live sessions and recent work visible, with secondary analytics and connected-account details collapsed.

Free provides a complete short-session experience: Natural and Steady rhythms, random word groups, sentence pauses in Natural, breaks, all insertion modes, and existing accessibility features. Existing limits remain 150 words/day, 30 minutes, and one unfinished session. Pro adds the Drafting preset, customizable effects and speed, long sessions, saved presets, imports and formatting, and editing remaining text/settings while paused. Pricing uses the shared plan descriptions.

The server resolves named presets itself. Free clients cannot change their preset's mistake rates or timing parameters by modifying a request. Presets are compiled into the existing saved execution plan, so this release does not need a schema migration and does not modify sessions already running.

These are automated edits. Temporary mistakes require explicit approval, and completed text must match the approved source. Google controls version-history grouping; neither the preset nor the interface promises a particular number or appearance of revisions.
